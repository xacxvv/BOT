# Их сургуулийн МТ төвийн туслах бот

Энэ бот нь Дотоод хэргийн их сургуулийн ажилтнуудад Мэдээлэл технологийн төвөөс
тусламж авах процессыг автоматжуулдаг.

## Ашигласан технологи
- Python 3
- python-telegram-bot 20+
- OpenAI Chat API
- SQLite (sqlite3 стандарт модуль)

## Файлуудын тайлбар
- `config.py` – Токен, API түлхүүр, DB байрлал зэрэг тохиргоог уншина.
- `database.py` – SQLite хүснэгтүүдийг үүсгэж, дуудлага/ажилтны CRUD үйлдэл.
- `ai.py` – OpenAI-г дуудаж монголоор 5–8 алхамтай зөвлөгөө гаргана.
- `bot_handlers.py` – Telegram команд, ярианы үе шат, callback логик.
- `main.py` – Бүх обьектыг холбож ботыг асаана.

## Хэрхэн ажиллуулах вэ?
1. ``python -m venv venv``
2. Linux/macOS: ``source venv/bin/activate``
   Windows: ``venv\\Scripts\\activate``
3. ``pip install python-telegram-bot==20.7 openai``
4. Орчны хувьсагч тохируулах: TELEGRAM_TOKEN, OPENAI_API_KEY
5. ``python main.py`` гэж ажиллуулна.

## Богино урсгал
- Ажилтан /start хийж кодоо оруулна.
- Асуудлын төрлөө сонгож тайлбар бичнэ.
- AI алхмууд илгээнэ, тус болсон эсэхийг тэмдэглэнэ.
- Тус болоогүй бол эрхлэгчид мэдэгдэж, инженер автоматаар оноогдоно.
